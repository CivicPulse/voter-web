    - resolvePreset("last-year") returns { date_from: Jan 1 last year, date_to: Dec 31 last year }

    - resolvePreset("custom") returns { date_from: undefined, date_to: undefined }
    - matchPreset(date_from, date_to) returns the matching preset key when dates match a preset
    - matchPreset(date_from, date_to) returns "custom" when dates don't match any preset
    - getDefaultDateRange() returns the resolved "next-3-months" date range
